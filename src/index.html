A month of daily passwords

Turn one recovery code into a full month of 8-digit passwords. Use the same code next time to get the same list back.

An 8-digit password is convenient, not strong. This tool does not protect against someone who captures your Wi-Fi traffic or has your device. Keep your recovery code private. Chat and notes apps may sync copies to the cloud; a downloaded file or a printout is safer.

Create a new list

The list covers every day in this month. A new list gets a new code, so it will not match an earlier list.

Hyphens, spaces, and lowercase are fine. The code's checksum catches most typos, but a valid code can still describe a different list.
